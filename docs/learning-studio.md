画面は「今日の練習」「復習」「プリント作成」の3つです。フレームワーク・外部サービスは追加していません。

| 責務                                               | 実装                                                   |

## 教材の正本と追加方法

フレーズの正本は `src/data/collections/phrases/*.json` です。JSONを読み込んだカテゴリー・年齢のバケットは旧 `phrase-data.js` より優先します。旧データだけにあった65問もJSONへ移し、旧ファイルは互換APIとして維持しています。静的配信でJSONを一部読み込めない場合は、古い教材で黙って続行せず、再読み込みを促します。

既存カテゴリーへの問題追加は、そのJSONの `items` への追加で学習・復習・プリントの共通プールに反映されます。`metadata.totalCount` と `_manifest.json` の件数も更新してください。新しいカテゴリーには、マニフェスト・画面のカテゴリー選択肢・URL設定の許容値の追加も必要です。

- `id`: 永続的な教材ID。英文を修正しても変更・再利用しない。
- `revision`: 改訂番号。省略時は1。英文・日本語・別解の変更時に増やす。
- `legacyEnglish`: v1記録から移行するための旧英文。過去の別名は消さない。
- `focusWords`: 実際の英文に含まれる、練習したい単語・表現。穴埋めの選択で優先する。未指定・空の場合は難易度別の語彙選択を使う。
- `acceptedEnglish`: その日本語・場面で確認した別解を、完成した英文として記載する。

数値の教材難易度と、画面の `easy/normal/hard`（空欄の数・選び方）は別です。年齢は主に日本語の表記と教材プールの区分であり、英語力の認定レベルではありません。

## 出題と採点

最大5問を重複なしで選びます。文字穴埋めは短い単語でも一部の文字を残し、アポストロフィを消しません。空欄は英文中の `start/end` オフセットとして管理します。保存・読み込みの際は範囲、順序、重なり、長さ、メタデータを検証し、HTMLは保存せず毎回エスケープして生成します。

入力を空欄に戻して完成文を作り、お手本または登録された `acceptedEnglish` と比較します。大文字小文字・全角英字・空白・曲がったアポストロフィは正規化します。別解の単語を独立に組み合わせて、未確認の文を正解にはしません。

自動採点は自由英作文の正誤判定ではありません。未登録の別解は復習対象になり、先生・保護者との確認を案内します。表示する文字数と紙の解答は「お手本の目安」「答え例」です。別解は現時点では一部の表現に限ります。

## 復習記録と移行

保存キー `english-note-maker.learning.v1` はそのまま、内容の `version` を2へ更新します。問題は「教材ID・年齢・穴埋めタイプ・難易度」で識別し、出題済みの英文・日本語・空欄をスナップショットとして保持します。入力された答えは保存しません。

v1記録は現在の英文または `legacyEnglish` から教材IDへ移行します。挑戦回数、連続正解数、復習日時を保持します。v1には空欄が保存されていないため、移行時に一度だけ作成します。

| 教材の状態           | 復習・保存セットの動作                                     |
| -------------------- | ---------------------------------------------------------- |
| 変更なし             | 同じ英文・同じ空欄                                         |
| 日本語などの修正のみ | 最新の説明に更新、空欄は保持                               |
| 英文を改訂           | 固定IDで履歴を維持し、最新英文の空欄を再生成。画面で通知   |
| 教材が見つからない   | 記録を保持し、復習可能件数から除外。該当セットは開始しない |

自力正解の間隔は1・3・7・14日（以後14日）。不一致やヒント使用はすぐ復習できます。これは端末の時計に基づく目安です。記録が壊れている・未対応の形式の場合は上書きせず、その画面内で練習を続けます。

## 問題セットの保存・再利用・印刷

結果画面でセットを保存し、一覧から再挑戦・印刷・書き出しができます。最大20セット、1セット最大5問です。上限時は自動削除せず、利用者に書き出しと整理を案内します。削除には確認があり、学習記録には影響しません。

セットは `english-note-maker.lessons.v1` に保存します。共有ファイルは `format: "english-note-maker.lesson", version: 1` のJSONで、250KB以下。問題・解答例・空欄は含みますが、学習記録や入力履歴は含みません。読み込みは別IDのセットとして追加し、既存セットを置き換えません。任意の未登録教材を作成するためのインポート機能ではなく、収録教材のセットを再利用する機能です。

改訂されたセットを開くと、最新の問題を保存し直します。英文が変わらなければ順番も空欄も変わりません。更新の保存に失敗した場合は画面で通知します。

「この問題をそのまま印刷」は解いたセットをそのまま渡します。印刷用の設定で別の問題は抽選しません。用紙の高さを測定し、必要なページ数を再計算するため、解答表示・罫線サイズの変更でも全問が残ります。固定セットではテーマ・年齢・ページ数などをロックし、「通常のプリント作成に戻る」で解除します。通常の印刷設定URLは従来どおり設定だけを共有し、問題セットそのものはJSONで共有します。

学習記録の端末間同期・複数利用者の切り替え・入力途中からの再開には未対応です。従来のカスタム例文は文章練習専用のままです。
