# 学習・復習の構成

画面は「今日の練習」「復習」「プリント作成」の3つです。既存の用紙生成処理はそのまま利用し、学習用の処理を以下に分離しています。

| 責務                                         | 実装                                                   |
| -------------------------------------------- | ------------------------------------------------------ |
| 単語／文字の穴埋め生成・HTMLエスケープ       | [cloze.js](../src/learning/cloze.js)                   |
| 答えの正規化・学習記録の検証と保存・復習予定 | [progress.js](../src/learning/progress.js)             |
| 学習セッション・入力・結果・復習画面         | [studio.js](../src/learning/studio.js)                 |
| 画面用デザイン・モバイル対応                 | [studio.css](../src/learning/studio.css)               |
| 用紙生成・出題キャッシュ・印刷               | [script.js](../script.js)、[styles.css](../styles.css) |

## 学習と保存

各セッションは選択した年齢・テーマのプールから重複なしで最大5問を選びます。文字の穴埋めに適さない短い文は単語の穴埋めにフォールバックし、空欄のない問題を出しません。

問題の識別子は「英文・年齢・穴埋めタイプ・難易度」です。同じ英文を別テーマから学んだ場合は同じ記録として扱います。教材JSONの数値の難易度と、画面の easy/normal/hard は別の情報として扱い、教材のメタデータで学習設定を上書きしません。

localStorage の `english-note-maker.learning.v1` に version と records を保存します。保存対象は出題条件、英文、挑戦回数、自力正解の連続回数、復習日時です。入力された答えは保存しません。保存失敗時は画面内の記録を保持し、利用者へ通知します。複数人の記録や複数端末の同期には対応していません。

間違い・ヒント使用時は復習日時を現在時刻にし、自力正解の連続回数をリセットします。自力正解が続くと、次回の復習を24時間、3日、7日、14日後（以後14日）へ延長します。予定は目安で、端末の時計を使用します。

復習では現在の教材から英文を再取得して問題を生成します。直後の「迷った問題をもう一度」は同じ空欄で再挑戦します。プリントへの移動は最初の問題のテーマ・年齢・難易度・穴埋めタイプを引き継ぎ、紙用の問題セットを作ります。ブラウザで解いた問題そのものを印刷する機能ではありません。

## 画面・用紙の互換性

`?view=learn`、`?view=review`、`?view=worksheet` で入口を指定できます。従来の `practiceMode` 付き共有URLはプリント作成画面を開きます。設定変更は replaceState で反映し、画面の選択を維持します。

印刷用の寸法・フォントは画面デザインから独立させます。穴埋めの出題順と空欄は、解答表示やレイアウト再計算で変わらないようキャッシュします。「別のフレーズを表示」やテーマ・年齢・難易度の変更でキャッシュをリセットします。
